Identificação do Projeto de Modelagem de Banco de Dados

Escopo: O banco de dados centralizado sustenta a operação industrial, armazém e distribuição B2B da fabricante Dolly. Contempla cadastro de clientes e tabelas de preço regionalizadas, catálogo e lotes de produtos sob rígido controle de validade (FEFO), controle transacional de pedidos, faturamento e contas a receber, gestão de rotas e entrega com canhoto digital, além de trilha de auditoria centralizada.

Tecnologia SGBD: MySQL Server 8.0+ (Storage Engine InnoDB, UTF-8 mb4, Collation utf8mb4_0900_ai_ci).
